# Acoustic L1/L2 Tests — Preliminary Summary

After Lobanov normalisation and acoustic quality control, L1 vs L2 contrasts were tested separately for each oral vowel and each formant dimension (F1, F2). Assumption checks used Shapiro-Wilk normality tests and Levene tests for homogeneity of variance. Depending on the assumptions, either t-tests/Welch tests or Mann-Whitney U tests were applied. P-values were corrected using Benjamini-Hochberg FDR.

Significant acoustic contrasts after FDR correction:

| Vowel | Feature |
|---|---|
| /a/ | F1 |
| /i/ | F2 |
| /u/ | F1, F2 |
| /y/ | F1, F2 |
| /ø/ | F1 |
| /ɑ/ | F1, F2 |
| /ɛ/ | F1 |

Interpretation must remain cautious. Some statistically significant effects are very small in magnitude, especially /a/ F1. These results should later be compared with confidence intervals and ROPE classifications to distinguish statistical significance from practical phonetic relevance.
